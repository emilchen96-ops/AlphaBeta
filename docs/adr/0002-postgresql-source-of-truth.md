# ADR 0002：PostgreSQL 是业务事实唯一来源

- 状态：Accepted

## 背景

账户、订单、成交、持仓、策略配置、事件和审计需要可恢复、可查询且具事务语义的记录。

## 决策

以 PostgreSQL 作为上述业务事实的唯一权威来源；Redis 仅承载缓存、Streams、锁、心跳、推送和短期状态。

## 原因

关系约束、事务、持久化和审计查询适合由 PostgreSQL 提供，避免把易失缓存误作账本。

## 后果

写入路径需围绕数据库事务设计，Redis 故障不能丢失已确认业务事实。

## 被否决方案

以 Redis 作为订单或持仓的唯一存储；在多个临时存储间手工对齐事实。
