# ADR 0006：后端与执行器实施双层风控

- 状态：Accepted

## 背景

策略错误、消息延迟、配置漂移、设备状态变化和外部异常都可能使单一风控点失效。

## 决策

后端在策略、账户和组合层进行第一层风险评估；Windows 执行器在 Broker 调用前执行独立第二层最终校验。任一层拒绝即订单不得执行。

## 原因

形成纵深防御，确保接近下单处仍可验证命令、账户、时效、限额和运行模式。

## 后果

需要维护两层规则的一致性和版本可追溯性，并接受执行器拒绝会使订单进入受控失败路径。

## 被否决方案

只在策略或后端做风控；让 AI、前端或策略绕过订单状态机直接下单。
