# ADR 0008：行情来源边界、优先级与幂等键

- 状态：Accepted
- 日期：2026-07-15

## 背景

M03 需要在没有真实供应商凭证和网络依赖的情况下完成可验证行情闭环，同时为未来只读适配器保留稳定边界。行情重复同步、来源切换和自然闭市不能制造重复事实或错误实时承诺。

## 决策

1. 以框架无关 `MarketDataAdapter` 作为唯一外部行情端口，应用服务不依赖供应商 SDK。
2. M03 默认只启用确定性 `DEMO` 和受限本地 CSV；真实外部入口保持显式 `DISABLED`。
3. 标的与外部代码通过 `instrument_mappings` 显式关联；自动来源选择只考虑已映射的 `ACTIVE` 来源，并按数值优先级升序。
4. K 线唯一键固定为标的、来源、周期、复权方式和 bar 时间；批量 Upsert 只在内容变化时更新。
5. 新鲜度按来源状态、数据质量、周期和交易窗口在查询时计算；M03 不宣称实时流。
6. 同步运行、事件和审计进入 PostgreSQL；M03 不启动 Outbox 发布器或 Redis Streams。

## 后果

开发和 CI 可离线复现；重复同步可计量为未变化；未来供应商接入必须新增适配器、映射和安全配置评审，而不能绕过端口。实时订阅、企业级交易日历和供应商故障切换仍是后续能力。
