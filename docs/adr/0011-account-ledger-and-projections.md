# ADR 0011：模拟账户采用只追加账本与可重建投影

- 状态：Accepted
- 日期：2026-07-15

## 背景

M04 需要可审计的模拟资金和持仓，同时支持并发成交、幂等重放、估值与差异核对。仅覆盖余额行会丢失业务历史，仅依靠事件总线又会扩大当前阶段范围。

## 决策

PostgreSQL 是唯一事实来源。每个业务动作创建唯一 `LedgerTransaction`，追加净额资金分录和必要的持仓分录；资金余额与持仓表作为同事务更新的可重建投影。Fill 记账固定先锁资金、后锁持仓，并以 Fill ID 建立数据库唯一约束。费用采用买入资本化、卖出冲减收入的移动加权平均成本法。估值快照和核对运行同样只追加。

## 后果

重复 Fill 不会重复记账，并发不会产生负资金或超卖；能够从账本发现投影漂移。代价是一次业务动作需要写多张表，未来更正必须使用反向分录。M04 不启用 Outbox 发布、Redis 流、撮合或 Broker。
