# ADR 0012：免费行情采用显式能力与用途边界

- 状态：Accepted
- 日期：2026-07-15

## 背景

M04.1A 需要在没有付费行情或账户凭据时验证真实数据闭环，但免费网页型接口没有 SLA，字段和可用性可能变化。

## 决策

固定使用 BaoStock 提供历史日线及可选 5/15/30/60 分钟线，使用 AKShare/EastMoney 提供 A 股快照和近期 1 分钟线。所有来源、DTO、缓存、API 和 UI 明示 `FREE_BEST_EFFORT`、`RESEARCH_ONLY`、`NON_TRADING_GRADE`。适配器只输出字符串数值；领域层只接受 Decimal。缺失上游时间保留为空，不伪造交易时间。

## 后果

系统能以可替换端口验证真实行情，但不能声明可靠实时、交易级或用于自动执行。第三方变更只影响基础设施适配器；默认 CI 不访问外网，真实连接由显式脚本验收。
