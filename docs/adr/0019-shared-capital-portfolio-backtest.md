# ADR 0019：共享资金组合回测采用单账户统一时间轴

- 状态：Accepted
- 日期：2026-08-03

## 背景

逐股独立回测为每只股票分配完整初始资金，适合比较策略样本，但无法表达多标的同时发出信号时
的资金竞争、持仓上限和现金释放。直接平均独立收益会形成不可实际执行的“组合”。

## 决策

共享资金组合回测使用一个 BacktestRun、一个模拟账户和一条全局事件时间轴。所有股票共享现金、
持仓和风险约束；同一时间先卖后买，多买入信号按确定性排序处理。组合继续复用既有信号、风控、
订单、模拟成交、账本和权益事实，不建立旁路成交引擎。

日线预筛和稀疏分钟加载属于性能优化；它们只能排除经证明不可能触发的日期，不能改变策略语义。
组合配置与执行模式写入批量任务快照，旧任务默认按逐股独立模式解释。

## 后果

- 可以生成可实现的组合资金曲线、回撤、持仓和逐股贡献。
- Worker 必须保证统一时间顺序、确定性竞争规则、幂等和可恢复。
- 逐股独立统计仍保留，但必须明确标注为样本比较，不能冒充组合绩效。
- 组合运行规模更大，报告与明细采用分段查询并保留 CSV 导出。
