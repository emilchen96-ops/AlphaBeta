# TA01 AI 调研报告结构

报告 Schema 版本为 `1`，包含标题、执行摘要、综合观点、置信度、十个固定章节、引用、局限与 Markdown 快照。

固定章节为：调研概览、市场环境、技术面、基本面、资讯与事件、看多论证、看空论证、风险与不确定性、综合结论、资料来源。快速或标准模式未运行的角色会显示“资料不足”，不会伪造内容。

每个角色输出至少包含：标题、摘要、主要发现、风险、不确定性和资料引用。研究经理额外输出综合观点、置信度与执行摘要。引用只能指向本次资料快照中的市场日线或本地资讯 `source_id`。

报告详情支持 Markdown 与 PDF 下载。导出内容与数据库报告快照一致；PDF 仅是 Markdown 的排版版本，不再次调用模型。报告必须包含“AI 生成，仅供研究参考，不构成投资建议”以及数据时滞、缺失角色、Fake Provider 等局限说明。
