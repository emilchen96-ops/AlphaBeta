# 回测规则

回测与实时策略必须使用统一的策略接口；差异只能来自受控的市场数据和执行模拟器。回测结论必须可复现、可解释且不暗示未来实盘表现。

## 时间与数据完整性

1. 引擎按事件时间推进，不得让策略读取当前事件之后才可获得的数据。
2. 行情、公司行动、财报和公告必须使用其实际可用时间，而非事后修订或发布日期的模糊替代。
3. 禁止任何未来数据泄漏，包括未来收盘价、复权信息、成分股幸存者偏差和事后修订指标。
4. 数据缺口、停牌、不可交易时段和异常数据必须显式建模，不得自动假设可成交。

## 成交模拟

回测需配置并记录交易费用、税费、滑点、最小交易单位、涨跌停、可用成交量限制、部分成交和未成交处理。订单只能在当时市场规则允许的时间与价格范围内成交；不能用无限流动性或理想成交替代现实约束。

## 可复现性

每次回测必须保存策略版本、参数、数据集/版本、时间范围、交易日历、执行假设、随机种子（如适用）和运行环境标识。相同输入与版本必须得到确定性结果；任何随机成分需被固定并在报告中披露。
