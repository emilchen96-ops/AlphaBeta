# BT01 网页界面

入口为 `/backtest`，详情为 `/backtest/:backtestId`。

创建表单从策略目录加载参数契约，支持 MiniQMT 本地历史数据、多标的、日期、初始资金、单次买入仓位、买入执行价格方式、最大允许高开、未成交处理、佣金/最低佣金/印花税/过户费、滑点、单次最多占当日成交量和幂等键。仓位比例统一覆盖策略模板中的旧固定数量参数，股数在 T+1 开盘按可用资金和整手规则计算。默认显示“下一交易日开盘价成交”，并明确说明 T 日收盘确认、T+1 开盘执行；高级模式仍可选择旧的信号日收盘限价语义。后端校验是最终权威。

详情展示运行状态与配置、核心指标、权益/回撤/现金/市值曲线、闭合交易、Signal、RiskDecision、Order、Fill、Timeline 和 Integrity 报告。K 线图以空心圆表示策略信号、实心圆表示实际模拟成交，避免把买卖信号误读为成交。空数据和失败运行使用明确状态，不伪造曲线或指标。

页面持续提示：这是历史日线回测；T 日收盘信号在下一根可用日线开盘执行；不使用实时行情、不连接券商、不产生真实交易；模拟结果不代表未来收益；费用、滑点和公司行为还原存在模型边界。页面不提供实盘、跟单、MiniQMT 或真实账户按钮。
