# BT01/BT02 网页界面

入口为 `/backtest`，详情为 `/backtest/:backtestId`。

创建表单从策略目录加载参数契约，支持 MiniQMT 本地历史数据、多标的、日期、初始资金、单次买入仓位、买入执行价格方式、未成交处理、佣金/最低佣金/印花税/过户费、滑点、单次最多占当日成交量和幂等键。仓位比例覆盖策略模板中的旧固定数量参数，股数按执行时可用资金和整手规则计算。默认选择“一分钟触发、下一根分钟开盘成交”，并展示自动准备历史数据、确认周期和乐观模式风险；仍保留下一交易日开盘和旧信号日收盘限价兼容语义。后端校验是最终权威。

详情展示运行状态与配置、核心指标、权益/回撤/现金/市值曲线、闭合交易、Signal、RiskDecision、Order、Fill、Timeline 和 Integrity 报告。K 线图以空心圆表示策略信号、实心圆表示实际模拟成交，避免把买卖信号误读为成交。空数据和失败运行使用明确状态，不伪造曲线或指标。

页面持续提示：这是历史模拟回测；分钟模式只在分钟闭合后确认，默认在下一根真实分钟开盘执行；
日线兼容模式仍为 T 日收盘信号在下一根可用日线开盘执行。页面不连接券商、不产生真实交易；
模拟结果不代表未来收益。详情页和批量页显示候选日、分钟加载量、数据准备与回放耗时，并提供
取消、失败项重试和 CSV 导出。批量分钟回测在股票尚未完成时仍显示候选交易日的准备进度，
包括已准备、尚缺和正在准备的股票数，避免把 MiniQMT 补数阶段误认为任务卡死。

多股票回测必须先选择语义。“共享资金组合回测”使用一个账户和统一时间轴，展示组合累计收益、
基准、超额收益、回撤、仓位、逐股贡献和拒绝原因；“逐股独立回测”继续为每只股票分配独立资金，
只用于横向比较，并展示收益分布和收益—回撤散点图。组合权益图默认使用百分比，以 0% 为共同
起点；回撤图标记峰值、谷值、恢复点、当前回撤和最长回撤期。

共享资金组合报告尚未生成或任务失败时，页面保留任务进度、重试入口和中文失败原因，不回退
到逐股独立统计组件，也不得因为组合摘要缺少逐股字段而显示 React 路由错误页。
