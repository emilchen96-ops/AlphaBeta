# BT01 网页界面

入口为 `/backtests`，详情为 `/backtests/:backtestId`。

创建表单从策略目录加载参数契约，支持多标的、日期、初始资金、订单类型、TIF、佣金/最低佣金/印花税/过户费、滑点、最大成交量参与率和幂等键。后端校验是最终权威。

详情展示运行状态与配置、核心指标、权益/回撤/现金/市值曲线、闭合交易、Signal、RiskDecision、Order、Fill、Timeline 和 Integrity 报告。空数据和失败运行使用明确状态，不伪造曲线或指标。

页面持续提示：这是历史日线回测；T 日收盘信号在下一根可用日线开盘执行；不使用实时行情、不连接券商、不产生真实交易；模拟结果不代表未来收益；费用、滑点和公司行为还原存在模型边界。页面不提供实盘、跟单、MiniQMT 或真实账户按钮。
