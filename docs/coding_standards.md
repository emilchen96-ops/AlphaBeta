# 编码标准

> M04.1A 外部行情必须在 Adapter 边界把 SDK/DataFrame/Cursor 转换为标准 DTO；字符串数值显式转为 `Decimal`，时间显式转为 UTC。领域层、应用层和 API 不得导入具体免费供应商 SDK。

> M04 记账代码必须使用 `Decimal`，禁止 float；固定先锁资金后锁持仓；账本仓储只暴露 append；API 不返回 ORM，不在前端重算权威会计结果。

1. Python 代码必须使用明确类型标注；公共边界优先使用可验证的数据模型。
2. TypeScript 必须启用严格模式，禁止以不受控的 `any` 绕过类型契约。
3. 采用统一命名：领域概念使用一致的英文术语；标识符、时间和金额单位必须在接口中明确。
4. 使用结构化日志，并携带适用的 `correlation_id`、`causation_id`、`order_id` 和设备标识；日志必须脱敏。
5. 禁止裸捕获异常。必须捕获具体异常、保留上下文、记录安全的错误信息并采取明确恢复或失败动作。
6. 领域层不得直接依赖 FastAPI、Redis、数据库驱动或具体 Broker SDK；外部依赖通过应用端口和 Adapter 隔离。
7. 所有 Broker 必须通过 Adapter 接入；策略不能调用 Adapter 或 Broker。
8. 数据库结构修改必须通过 Migration，并配套升级和必要的回滚/兼容性考虑。
9. 公共 API、消息和跨模块接口必须有自动化测试及明确的版本/兼容性策略。
10. 代码评审应检查领域边界、幂等性、审计、时间语义、敏感信息和失败恢复，而不只检查正常路径。
11. 免费行情请求必须经共享限速、有限重试和熔断器；最大并发为 1，禁止逐股高频最新价请求、无限重试和代理绕过。
12. Redis Quote 更新必须通过单调 revision、稳定 payload hash 和乱序保护；Pub/Sub 只用于可丢弃行情，不得替代订单可靠消息。
13. WebSocket 客户端应复用单一连接、合并订阅、限制队列并丢弃旧 revision；页面卸载必须释放自身订阅。
