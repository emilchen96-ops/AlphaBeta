# D03 分钟数据页面

访问 `http://127.0.0.1:5173/intraday-market-data`，左侧菜单为“分钟数据”。页面包含 Provider、导入任务、覆盖度、跨周期聚合、质量、Readiness 和分钟K线预览七个区域。

首次使用：

1. 在“导入任务”点击 Fixture 导入；它生成至少 2 只股票、5 个完整交易日，另含一个不完整日和一个停牌日案例；
2. 查看覆盖度的 1/5/15/30/60 分钟数量；
3. 在“数据质量”运行检查；
4. 在 “Readiness” 确认数据状态，同时确认 BT02/分钟回放仍显示代码尚未开发；
5. 在预览选择标的、周期和 RAW/QFQ。午休无 Bar，图中自然断开。

页面没有上传按钮。本地 CSV 通过页面展示的 CLI 模板导入。页面所有分钟内容均标记“历史数据 · 非实时”，不连接行情 WebSocket。

覆盖度可按 Fixture Universe、单标的、周期与 `[开始日期, 结束日期)` 筛选，并分别展示 RAW、
QFQ、完整/缺失 Session、最近导入与质量错误。聚合与质量区域可选择日期范围和目标周期；
Bar API 使用时间 cursor 分页，单次仍受 5,000 根上限约束。
