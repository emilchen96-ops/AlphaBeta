# 自然语言策略

普通用户默认从一句中文描述开始。处理顺序为：文本规范化、确定性本地解析、严格 Schema
与语义校验、中文预览、用户确认。AI 辅助当前受控关闭；即使 AI 不可用，核心示例仍可解析。

核心示例：

```text
10日价格突破 + 1.2倍成交量，5日均线退出，单只股票、两年日线
```

其含义为：收盘价突破此前 10 个交易日最高价，并且成交量超过此前 10 日平均成交量的
1.2 倍时进入；收盘价跌破 5 日简单移动平均线时退出。此前窗口排除当前 K 线。页面在
确认前不会启动回测；含糊或不支持的表达返回 `PARTIAL`，用户需要在规则编辑器中修正。

自然语言只生成 `StrategySpec`，不会执行输入文本、生成 Python 或访问交易模块。
