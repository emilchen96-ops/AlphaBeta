# 研究产品模式

AlphaDesk 默认使用 `RESEARCH_ONLY`。普通导航只保留首页、行情、自选股、智能选股、
策略研究、资讯研究、研究记录、数据中心和设置。订单、成交、持仓、风控和券商执行代码
仍保留用于历史模拟事实，但不作为普通产品入口；直接访问交易页会显示研究模式说明。

服务端 `GET /api/v1/system/status` 是产品模式的权威来源，浏览器参数不能扩大能力。
MiniQMT 在本模式中仅提供只读行情，快速回测读取已经同步到 PostgreSQL 的历史数据，
不会调用 MiniQMT 下单或读取真实账户。

旧策略、研究运行、研究信号、回测和回放 URL 保留跳转，避免旧书签直接失效。
新的统一入口是 `/research/backtest`，历史结果位于 `/research/history`。
