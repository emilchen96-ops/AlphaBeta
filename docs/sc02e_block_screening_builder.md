# SC02-E 积木式选股器与产品化条件目录

## 产品入口

智能选股采用四个固定页签：

1. **条件选股**：选择股票范围、添加条件积木、设置参数、组合规则并开始选股。
2. **我的规则**：保存、编辑、复制、归档、恢复和再次运行个人规则。
3. **常用模板**：把系统模板载入同一个积木编辑器，确认后运行。
4. **历史结果**：查看运行状态、逐股票条件事实、失败分类，并继续加入自选或快速回测。

旧自然语言解析后端保持兼容，但不再作为普通用户入口。前端不展示 `condition_key`、参数键、
UUID、幂等键或原始 `ScreeningSpec`。

## ConditionCatalog

`ConditionDefinition` 是前后端唯一的条件能力来源，至少声明：中文名称和说明、分类、参数
Schema、比较方式、适用周期、所需字段、历史窗口、单位、Evaluator、Renderer、解释模板、
版本、启用状态和弃用关系。新增条件必须先注册到目录，再由安全的确定性 Evaluator 实现；
不得接受任意 Python、SQL 或表达式执行。

当前目录包含 18 个条件定义。`BOTTOM_VOLUME_EXPANSION` 与 `LIMIT_UP_PULLBACK` 仅用于旧规格
兼容，已从新建条件目录隐藏。

## 规则结构和限制

- `ScreeningSpec` v2 使用条件节点和条件组节点。
- 条件组支持“全部满足（AND）”和“任一满足（OR）”。
- 最多两层条件组、20 个原子条件；超限在前后端同时拒绝。
- 主流程默认全 A 股、日线、不复权、按标准条件得分降序、返回前 50 名。
- 选股前继续调用 SC02-D：规划共同交易日窗口、检查本地覆盖、按缺口补数、复检质量，
  然后调用原 SC02 执行引擎。

## 模板等价语义

“底部放倍量”由以下三个普通积木组成：

- 60 日价格区间位置不高于 20%；
- 当前成交量不低于此前 20 日均量的 2 倍；
- 当日收阳。

“涨停回踩”由以下四个普通积木组成：

- 近 20 个共同交易日存在可靠涨停事件（不把筛选日当作锚点）；
- 当前价格距离最近涨停起涨锚点不超过 3%；
- 当前价格不低于锚点的 98%；
- 当前成交量不超过该涨停日成交量的 50%。

三个事件关系积木共享同一个“最近有效涨停事件”，避免各自选择不同锚点。领域测试逐股票
比较了旧复合 Evaluator 与新组合规格的匹配状态和关键事实，保证迁移语义一致。

## 安全边界

本阶段只重构研究选股体验。它不会创建策略信号、订单或成交，不访问交易接口，不改变账户、
持仓、账本和风控状态。选股结果是确定性规则筛选事实，不构成投资建议。
