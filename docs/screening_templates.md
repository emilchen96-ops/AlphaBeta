# 智能选股模板

SC02-C 将系统内置选股形态作为数据驱动模板展示。模板只保存受控
`ScreeningSpec`，不会执行用户代码，也不会创建订单。

当前模板不少于六个：涨停后回落、底部放量、成交量异常、涨停回撤、放量突破和均线趋势。
模板卡片必须展示中文名称、适用数据、规则摘要和启用状态。停用模板可以查看，但不能启动。

使用方式：

1. 打开“智能选股”并进入“选股模板”。
2. 选择模板，点击“使用模板”。
3. 在自然语言页检查筛选日期、股票范围、排除项和参数。
4. 确认中文规则预览后再开始选股，或先保存为个人方案。

模板是初始配置，不是不可修改的策略。用户修改后保存时会生成独立的个人方案。
