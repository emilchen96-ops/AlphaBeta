# 安全规范

> M04.1A 免费行情不使用券商凭据或行情 Token，不做代理轮换或访问限制绕过。外部访问只发生在独立 Worker/CLI Adapter；浏览器不能提交上游 URL，也不存在通用代理接口。

> M04 安全边界：仅允许 `SIMULATED` 账户；资金 API 只修改本地模拟账本；无公开 Order/Fill 写接口；不保存 Broker、银行或支付凭证；系统仍不得部署公网。

## M04.1A 行情与 WebSocket 安全

- AKShare/BaoStock SDK、DataFrame 和 Cursor 被限制在基础设施 Adapter 内；日志只记录安全计数与错误摘要，不记录完整上游响应或全部自选股。
- WebSocket 校验 Origin、schema 版本、消息类型、UUID 和单连接订阅上限，只接受内部 Instrument ID，不接受供应商代码或任意 URL。
- Redis Quote、Leader Lock、心跳和 Pub/Sub 均为临时运行数据；Redis 不是历史事实来源，也不承载订单消息。
- 当前系统没有认证，API/Web 只能绑定可信本机地址，免费行情启用不改变“禁止公网部署”的结论。
- 上游拒绝、超时或结构变化必须受限重试、退避、熔断并安全降级，禁止代理规避或无限重试。

## M03 行情数据安全补充

M03 没有真实供应商凭证。外部 Adapter 默认禁用；本地 CSV 拒绝 URL，限制文件大小、行数和列集合，不回显或记录文件内容。API 设定分页与 K 线返回上限，前端不保存 Token、券商账户或交易权限。启用任何真实来源前必须单独完成密钥存储、网络出口、授权范围、限流和数据许可评审。

## 凭证与权限

前端不得持有券商密钥、账户口令或可下单凭证。Git 仓库、示例文件、日志、测试夹具和普通配置文件均不得提交任何真实密钥、账户信息或 Token。敏感材料仅可由受控的本地安全存储或后续批准的密钥管理机制按最小权限提供。

## 执行器通信

每台执行器必须拥有可登记、可吊销的设备身份。命令与关键回执应验证消息签名、时间戳、Nonce、来源设备、目标账户和命令有效期；失效、重放或身份不匹配的消息必须拒绝并审计。密钥轮换、设备吊销和权限变更都必须具备明确生效时间和审计记录。

## 运行防护

- 按最小权限授予用户、服务、设备和账户权限。
- 对日志、错误、事件和告警执行脱敏，避免泄漏账户号、凭证、完整订单敏感字段或个人信息。
- 本地执行器的敏感状态使用操作系统提供或等效的安全存储；不得以明文文件替代。
- 紧急停止应能阻断新交易指令并保留审计、查询和对账能力。
- 所有安全相关失败、认证拒绝、授权变更、密钥轮换和急停操作必须记录审计。

本文不包含任何真实密钥、账户、Token 或看似可用的凭证示例。

## M01 本地开发约束

- `.env`、证书和常见密钥文件由 `.gitignore` 排除；`.env.example` 仅包含明确的本地占位值。
- 浏览器只能读取 `VITE_` 前缀的 API/WebSocket 地址，不得注入数据库、Redis 或券商配置。
- PostgreSQL 和 Redis 默认不映射宿主机端口；API 与 Web 仅绑定 `127.0.0.1`。
- M01 不实现用户认证、硬编码用户或虚假 JWT，因此系统只能在可信本机开发环境运行，禁止部署公网。
- API 错误响应隐藏堆栈和内部路径；服务端结构化日志禁止记录 Authorization、密码和完整连接串。
- Correlation ID 仅接受长度不超过 128 的受限字符集，异常输入会被安全 UUID 替换。

## M02 数据安全约束

- `trading_accounts` 和 `executor_devices` 只保存业务标识、状态、能力和公钥指纹等非秘密元数据，不保存券商密码、交易 Token、私钥或数据库凭证。
- JSONB 事件、审计、参数和元数据字段同样禁止秘密；测试与文档只使用显式占位值。
- 集成测试的降级/重建操作必须同时满足显式 opt-in 与数据库名包含 `test`，否则立即拒绝执行。
- M02 没有认证、授权、Broker 或实盘能力，服务仍只能用于可信本机开发，不得因数据表已建立而扩大部署边界。
