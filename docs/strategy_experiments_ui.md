# S02-B2 策略批量研究页面

S02-B2 在现有策略目录和 S02-B1 六个真实 API 之上提供批量研究配置、实验列表与实验结果页面。创建页根据策略注册表返回的参数定义生成网格编辑器，支持 integer、decimal、boolean、string 和 enum；每个参数可以保留多个候选值，留空表示使用注册表默认值。Decimal 候选值按字符串传输和展示。

组合数量预览是各参数非空候选数的乘积，未配置参数按一个默认取值计算。界面以 50 作为当前部署的提示值，但不会截断或删除候选值，服务端的 `strategy_experiment_max_combinations` 校验始终是最终权威。相同规范化表单在重复提交时复用同一幂等键；表单事实改变后生成新的幂等语义。同步创建期间按钮禁用，页面显示真实请求状态，组件卸载会取消请求。

实验列表显示状态、版本、周期、标的数、组合数、完成/失败数、Signal 数和时间，支持策略、状态、创建时间与分页筛选。`PARTIAL_FAILED` 明确表示部分组合失败，不按成功展示。实验详情包含原始网格、组合运行表、Signal 对比表和 Jaccard 重合度矩阵；组合可以跳转到既有 StrategyRun 详情或携带运行 ID 的 Signal 页面。

Signal 对比只描述 K 线处理数、BUY/SELL/总 Signal 数、首次/末次触发时间和触发标的数。重合度以 `(instrument_id, bar_timestamp, signal_type)` 为身份计算 Jaccard 相似度，矩阵对角线为 1，并保留后端返回的字符串精度。高触发频率或高重合度不表示策略质量。

本页面不是绩效回测，不评价参数优劣，也不计算资金曲线或交易绩效。Signal 不是 Order；页面不会创建 Order、RiskDecision 或 Fill，不调用风控、Broker、MiniQMT，不修改现金、持仓或账本，也没有实时策略调度能力。
