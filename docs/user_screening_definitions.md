# 我的选股方案

“我的选股方案”保存用户确认过的结构化选股条件，包括名称、说明、原始中文描述、
股票范围、排除项、筛选条件、排序规则和版本号。

## 版本与状态

- 新建方案产生版本 1。
- 编辑方案不会覆盖旧内容，而是生成新的不可变版本。
- 复制会创建新的方案身份和独立版本链。
- 归档只隐藏日常使用入口，不删除历史运行；归档方案可以恢复。
- 再次运行会先载入最新版本供确认，不会自动执行。

每次运行保存当时的完整快照及其方案版本。以后编辑方案不会改变历史结果，因而可以审计
“当时用什么条件得到了什么结果”。

方案内容只允许由条件目录支持的字段。服务端会再次校验参数范围、时间周期、价格复权模式
和全部 A 股范围，不能借此提交 Python、SQL、脚本或动态表达式。
