# UX02 研究模式与任务式导航

AlphaDesk 默认运行在 `RESEARCH_ONLY`（研究模式）。该模式面向个人行情研究，主导航只保留九个任务入口：

1. 首页
2. 行情
3. 自选股
4. 智能选股
5. 策略研究
6. 资讯研究
7. 研究记录
8. 数据中心
9. 设置

原有策略运行、研究信号、扫描运行、历史回放和数据中心等页面仍作为详情或高级工具保留，
旧 URL 不失效。独立订单、成交、持仓和风控页面在研究模式下不可从主导航进入，直接访问也会
跳转到设置页说明原因。回测内部生成的模拟订单与成交仍属于隔离的历史研究事实，不会发送到
MiniQMT 或券商。

## 产品模式

后端配置：

```text
ALPHADESK_PRODUCT_MODE=RESEARCH_ONLY
```

`GET /api/v1/system/status` 返回 `product_mode`，前端以服务端状态为准。可选值：

- `RESEARCH_ONLY`：默认研究模式。
- `FULL_SIMULATION`：开放本地模拟账户、订单、成交和风控页面；仍不是实盘。

本次不提供网页切换模式的开关，避免浏览器自行扩大产品权限。修改环境变量后需要重启 API。

## 策略研究入口

“策略研究”是统一入口：

- “快速回测”是推荐主流程，输出收益、回撤、交易和完整性结果。
- “策略模板”解释策略用途和参数。
- “参数比较”比较参数组合产生的研究信号，不等同于收益回测。
- “策略运行、研究信号、历史回放”归入高级记录，用于解释触发过程。

浏览器快速回测固定提交 `data_source_code=MINIQMT`，使用已同步到 PostgreSQL 的 MiniQMT
历史数据。正式页面不再暴露 BaoStock 或 Fixture 选择。`BT01_DEMO` 仅保留给开发测试和 CLI
确定性验收。

## UX02-B 策略入口

自然语言策略、可视化规则确认、我的策略版本和快速回测已经接入。自然语言只生成受控
`StrategySpec`，不提供用户自定义脚本沙箱。MiniQMT 交易、撤单和账户读取仍未包含。
详见 [自然语言策略](natural_language_strategy.md) 和
[快速回测工作流](quick_backtest_workflow.md)。

### UX02-KNOWN-001：历史回测指纹异常导致回测列表整体不可用

- 记录日期：2026-07-25
- 修复日期：2026-07-25
- 状态：已修复并通过真实数据与浏览器验收
- 影响页面：`/backtest` 的“我的回测记录”
- 用户可见现象：页面显示“无法连接 AlphaDesk API”
- 实际服务状态：FastAPI、PostgreSQL、Redis 均在线，与 MiniQMT 是否登录无关
- 实际后端错误：`GET /api/v1/backtests` 返回 `500`，领域校验报错
  `request fingerprint does not match configuration`
- 初步原因：至少一条历史回测记录保存的 `request_fingerprint` 与其持久化
  `configuration` 不一致；列表查询在重建领域对象时被严格校验中断，导致一条异常记录拖垮
  整页数据。

修复验收结果：

1. 识别并安全迁移或修复不一致的历史记录，不以直接删除研究记录作为默认方案。
2. 单条历史记录异常不得导致整个回测列表不可用，并应保留可审计的异常信息。
3. 前端必须区分网络不可达、请求超时和服务端 `5xx`，不得再将后端内部错误显示为
   “无法连接 AlphaDesk API”。
4. 增加历史配置版本或异常指纹记录的回归测试。
5. 验收时确认 MiniQMT 未登录的情况下，已有回测记录仍可正常查询；仅依赖 MiniQMT 的
   新行情读取或新回测应显示独立、准确的行情源提示。

修复由 `0022_ux02` 数据迁移、回测列表兼容读取和外层 CORS 错误响应共同完成。迁移仅为
4 条缺少 D02 复权字段的旧配置补入 `strategy_price_adjustment_mode=RAW` 并重新计算冗余
校验指纹，没有删除或重建任何回测结果。验收数据库内 8/8 条回测配置均具备该字段，
`GET /api/v1/backtests` 返回全部 8 条记录。
