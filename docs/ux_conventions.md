# UX01 前端可读性规范

UX01 不改变订单、风控、账本、回测或行情的领域语义，只调整浏览器端的展示与操作入口。

## 中文优先

- 面向个人用户的标题、按钮、表头、状态、枚举和错误提示使用中文。
- 必须保留行业缩写时使用“中文（英文）”，例如“研究信号（Signal）”“前复权（QFQ）”。
- 后端仍使用稳定的英文枚举和参数键；前端通过统一映射展示，不修改 API 与数据库值。

## 标的与内部编号

- 股票优先显示“名称（代码.市场）”，例如“浦发银行（600000.SH）”。
- UUID、幂等键、关联编号和运行编号是审计字段，不作为列表主信息。
- 详情页确需排查时仅展示短编号，并提供复制完整值的能力。
- 测试或演示数据默认隐藏；用户可通过“显示测试数据”显式查看。

## 数值语义

- 金额带人民币符号并固定两位小数；数量去除无意义的科学计数法和尾随零。
- 比率字段以百分比输入和展示，提交 API 时转换回小数比例。
- 缺失值统一显示“—”，不得把缺失行情或不可估值状态显示为零。

## 关键交互

- 扫描器的“创建扫描运行”打开配置对话框，用户可选股票、截止时间与规则参数。
- 回测和策略研究的幂等键由前端自动生成，不要求普通用户理解或填写。
- 风控列表以结果、来源、股票、账户和原因作为主信息；决策编号仅保留在详情审计区。
- 行情页把数据源状态与业务内容分区，MiniQMT 未配置时明确显示“尚未配置”。
- 自选股“盘中监控”只表示它可驱动期望订阅；期望订阅与代理实际订阅必须分别展示。
- MiniQMT 行情页面默认隐藏订阅 UUID、计划版本、幂等键和 XtQuant 原始返回码。

## 安全边界

- UX01 本身不接入 MiniQMT；后续 L2.5-A 只增加只读行情，不增加实盘下单，不弱化风控，
  也不伪造真实行情。
- 研究信号、扫描结果和回测结果均不构成投资建议。
