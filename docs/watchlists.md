# 自选股业务规则

自选列表是单用户、本地的展示组织能力。它只引用 `instruments` 主数据，不复制行情，不产生 Signal，也不能触发订单。

## 规则

- 列表名称全局唯一，名称最长 128 字符，描述最长 1000 字符。
- 同一列表不能重复加入同一标的；条目数量由 `ALPHADESK_WATCHLIST_ITEM_LIMIT` 限制。
- 备注去除首尾空白后最长 500 字符；空备注存为 `NULL`。
- 排序请求必须提交该列表全部且不重复的条目 ID；服务端原子更新连续 `sort_order`。
- 删除列表级联删除其条目，但不会删除标的、来源映射或 K 线；其他行情外键均使用 `RESTRICT`。

## API 与审计

`/api/v1/watchlists` 提供列表创建、读取、修改和删除；`/{id}/items` 提供添加、备注修改、移除和重排。每个成功写操作在同一 PostgreSQL 事务中写入领域事件和审计日志，Correlation ID 贯穿请求。M03 不为这些事件创建或发布 Outbox 消息。

页面提供列表选择、新建/编辑/删除、标的搜索、添加/移除、上下移动和备注的后端能力。浏览器不会保存供应商 Token 或交易凭证。
